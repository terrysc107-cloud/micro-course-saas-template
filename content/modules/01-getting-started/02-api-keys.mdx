## Getting Your API Key

Go to [console.anthropic.com](https://console.anthropic.com) and sign in (or create an account). Navigate to **API Keys** and click **Create Key**. Give it a descriptive name like "claude-code-local".

Copy the key immediately — you won't be able to see it again. It starts with `sk-ant-`.

## Setting Up the Environment Variable

The safest place to store your key is as an environment variable — never hard-code it in source files or commit it to Git.

**Permanent setup on Mac/Linux:**

Open your shell config file:
```bash
nano ~/.zshrc   # or ~/.bashrc if you use bash
```

Add this line at the bottom:
```bash
export ANTHROPIC_API_KEY="sk-ant-your-key-here"
```

Save and reload:
```bash
source ~/.zshrc
```

Verify it's set:
```bash
echo $ANTHROPIC_API_KEY
```

**Per-project `.env` file:**

For project-specific keys (useful when working with teams), create a `.env` file in your project root:
```
ANTHROPIC_API_KEY=sk-ant-your-key-here
```

Make sure `.env` is in your `.gitignore`:
```bash
echo ".env" >> .gitignore
```

Claude Code will automatically pick up variables from `.env` files.

## Understanding Costs

Claude Code uses Claude 3.5 Sonnet or Claude 3.7 Sonnet by default. These are among the most capable and cost-efficient models Anthropic offers.

**Rough cost guide:**
- Light session (quick edits, questions): ~$0.05–$0.20
- Medium session (building a feature): ~$0.50–$2.00
- Heavy session (full refactor or large codebase): ~$2–$10

Most developers spend $20–$100/month on heavy Claude Code usage. For the productivity gains, it's one of the best ROI tools available.

## Setting Spending Limits

To avoid surprise bills, set a monthly spending limit:

1. Go to [console.anthropic.com/settings/billing](https://console.anthropic.com/settings/billing)
2. Click **Spending Limits**
3. Set a monthly cap (e.g., $50)

Anthropic will email you when you approach your limit and stop processing requests once you hit it.

## Keeping Your Key Secure

- **Never commit your key to Git** — use `.gitignore`
- **Never paste it in Slack, Discord, or public forums**
- **Rotate your key** if you suspect it was exposed (just create a new one in the console)
- **Use separate keys** for local dev vs. production environments

<Callout type="warning">Anthropic API keys exposed in public GitHub repos are scraped by bots within minutes. If you accidentally commit a key, go to console.anthropic.com immediately, revoke it, and create a new one — do not just delete the commit, as the key may already be harvested from git history.</Callout>

<Callout type="tip">Setting a spending limit of $50-100/month when you first start out is a great safety net. You can always raise it once you understand your usage patterns — it takes 30 seconds in the billing console and prevents any surprise charges.</Callout>

<KeyPoint>Your API key is a secret credential — store it only as an environment variable outside of version control, set a monthly spending cap in the Anthropic console, and use separate keys for development versus production.</KeyPoint>
