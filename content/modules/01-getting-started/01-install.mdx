## Welcome to Claude Code Mastery

You're about to learn one of the most powerful developer tools available today. Claude Code is a command-line tool that brings Anthropic's Claude AI directly into your terminal — where you do your real work.

Unlike chat interfaces, Claude Code understands your **entire project**. It reads your files, writes code, runs commands, and helps you ship faster than you ever thought possible.

## Prerequisites

Before installing, make sure you have:

- **Node.js 18 or higher** — check with `node --version`
- **An Anthropic API key** — get one at [console.anthropic.com](https://console.anthropic.com)
- **A terminal** — Terminal on Mac, Windows Terminal, or any Linux shell

## Install Claude Code

Open your terminal and run:

```bash
npm install -g @anthropic-ai/claude-code
```

This installs Claude Code globally so you can use it from any project folder on your machine.

**Verify it worked:**

```bash
claude --version
```

You should see a version number. If you get "command not found", your npm global bin directory may not be in your PATH. Fix it with:

```bash
export PATH="$PATH:$(npm root -g)/../.bin"
```

Add that line to your `~/.zshrc` or `~/.bashrc` to make it permanent.

<Callout type="tip">After adding the export line to your shell config, run `source ~/.zshrc` (or open a new terminal tab) to apply it immediately — you should not need to restart your machine.</Callout>

## Set Your API Key

Claude Code needs your Anthropic API key. Set it as an environment variable:

**Mac / Linux:**
```bash
export ANTHROPIC_API_KEY=sk-ant-your-key-here
```

To make it permanent, add that line to your `~/.zshrc` or `~/.bashrc`, then reload:

```bash
source ~/.zshrc
```

**Windows (PowerShell):**
```powershell
$env:ANTHROPIC_API_KEY="sk-ant-your-key-here"
```

<Callout type="warning">Never commit your API key to a Git repository. If you paste it directly into a file that gets committed, rotate it immediately at console.anthropic.com — leaked keys can rack up thousands of dollars in charges within hours.</Callout>

## Launch Claude Code

Navigate to any project folder and type:

```bash
claude
```

An interactive session opens. You will see a prompt where you can start typing to your AI pair programmer, which has full context of the code in your directory.

## What Happens Under the Hood

When you run `claude`, it:

1. Scans your project directory structure
2. Reads relevant files to build context
3. Connects to the Anthropic API with your key
4. Opens an interactive session ready for your first prompt

<KeyPoint>Claude Code is a global CLI tool that connects your terminal directly to Claude — install it once with npm, set your API key as an environment variable, and run `claude` from any project folder to start an AI-powered coding session.</KeyPoint>
