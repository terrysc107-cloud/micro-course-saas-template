## Start Here

You do not need to have shipped code. You do not need to already know a terminal, git, or a programming language. You need a computer, a browser, and a willingness to type commands this course will show you.

This is **Claude Code Class**, an independent course by **AI by Design**. It is not an official Anthropic training product. It will not turn you into a computer scientist. It teaches the minimum so you can use Claude Code without handing your files to a tool you cannot supervise.

<Callout type="info">
Independent educational product by AI by Design. Not affiliated with or endorsed by Anthropic.
</Callout>

## What You Will Be Able To Do

By the end of Foundations you will be able to:

1. Point at a file and a folder and know the difference
2. Open a terminal and run a command
3. Ask git what changed (`status`), see the change (`diff`), and save a snapshot (`commit`)
4. Read a diff well enough to say yes, no, or "explain this line"

Those four skills are the safety net. Claude Code can edit files and run commands. If you cannot see what it did, you are not using it — you are hoping.

## What This Course Is Not

- **Not a CS course.** We will not teach algorithms, big-O, or a programming language from scratch.
- **Not a "never look at the code" product.** If you want a tool that writes things you never read, skip this course. That is not a safe way to work.
- **Not passive income.** This teaches a skill. What you do with it is on you. Nobody here can promise a result.
- **Not an official Anthropic training product.** For that, go to Anthropic.

<Callout type="warning" title="The one thing we will not remove">
You must still learn to read a diff. That is not gatekeeping. It is the only way you stay in charge of your own files.
</Callout>

## The Loop You Will Keep Seeing

The whole course teaches one workflow:

**Inspect → Plan → Build → Review → Test → Ship**

In plain language:

- **Inspect** — look at what is already there before you change it
- **Plan** — agree on the approach before files get edited
- **Build** — make a small change
- **Review** — read the diff
- **Test** — check that it actually works
- **Ship** — save a version you can undo

You will practice this on a small project that lives on your computer. You do not need a company, a team, or a production website.

## How To Use The Lessons

Each lesson is written. There may not be a video. Read it, try the commands, take the quiz. If a lesson and the [official Claude Code docs](https://code.claude.com/docs/en/overview) disagree, trust the docs and tell us.

Claude Code changes often. This course teaches habits that survive those changes: read first, change small, keep an undo.

<KeyPoint>This course teaches the minimum so a beginner can use Claude Code safely — and the non-negotiable part of that minimum is learning to read a diff.</KeyPoint>
