## Micro-SaaS: The Solo Developer's Opportunity

A micro-SaaS is a small, focused software product that solves one specific problem for a specific audience and charges a recurring monthly fee. It does not need investors, a team, or years to build.

The sweet spot with Claude Code: products that would have taken 3 months alone now take 3 weeks.

## Finding the Right Idea

The best micro-SaaS ideas are:

- **Specific** — "invoice reminders for freelance designers" beats "invoicing for everyone"
- **Painful** — the problem costs people time or money right now
- **Reachable** — you can find and talk to potential customers
- **Proven** — there are existing tools, which means there is demand (compete on niche, not on creating demand)

**Finding ideas with Claude Code:**

```
> I have 5 years of experience as a freelance web developer.
  Based on that background, suggest 10 micro-SaaS ideas I could build.
  For each: the target customer, the core problem it solves, 
  why someone would pay for it, and a rough monthly price.
  Focus on ideas where the MVP could be built in 2-3 weeks.
```

## The Stack: What You Already Know

You do not need to learn anything new. Build on the exact stack from this course:

- **Next.js + Tailwind** — frontend
- **Supabase** — database, auth, file storage
- **Stripe** — subscriptions (use the checkout pattern you already learned)
- **Vercel** — deployment

Claude Code knows this stack deeply. Use what you know.

## The 3-Week MVP Plan

**Week 1: Core feature**
```
> I am building a tool that lets freelancers create branded PDF invoices 
  and send payment reminders. 
  
  Week 1 goal: user can create an invoice with line items, see a preview, 
  and download as PDF.
  
  Start with the database schema: invoices, line_items, clients tables.
  Follow our standard Supabase + Next.js patterns.
```

**Week 2: Payment + user management**
```
> Add Stripe subscription checkout (monthly plan at $19/mo)
  and a basic dashboard showing all invoices with status.
  Gate the invoice creation behind the subscription check.
```

**Week 3: Polish + launch**
```
> Pre-ship review of the entire app.
  Then build the landing page using the marketing page pattern from 
  our course, targeting "freelance invoice tool" keywords.
```

## Pricing Strategy

For a solo-built micro-SaaS:

- **$9-29/month** — impulse buy range, low churn
- **$49-99/month** — business tool range, buyer is a company not an individual
- **One-time fee** — simpler, but harder to sustain without constant new customers

Start at $9-19/month. You can always raise prices. It is much harder to lower them.

## Launch Sequence

1. **Build** (2-3 weeks with Claude Code)
2. **Beta test** (share free access with 5 people in your target audience for feedback)
3. **Soft launch** (post in relevant communities: Reddit, X/Twitter, Indie Hackers, LinkedIn)
4. **First paying customer** — do not move on until you have one
5. **Iterate** — only build what your first customers ask for

## From Zero to $1,000 MRR

Month 1: Launch, find first 3 paying customers at $19/month = $57 MRR
Month 2-3: Referrals, word of mouth, content = 20-30 customers = $400-570 MRR
Month 4-6: SEO, product-led growth = $1,000+ MRR

This is achievable for a focused solo developer with the right niche.

## Summary

Micro-SaaS is the highest-leverage use of Claude Code. Small, specific, recurring revenue. Use the stack you know. Ship fast. Validate with real customers before building more.
