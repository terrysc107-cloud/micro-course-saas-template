## Python + Claude Code

Python is one of the best languages to use with Claude Code. Scripts, automation, data processing, API integrations — Claude handles the boilerplate so you can focus on the logic.

<Callout type="tip">Always specify your Python version and key dependencies at the start of your prompt — "Python 3.11, using the built-in csv module, no pandas" or "Python 3.10+, use httpx not requests." This prevents Claude from defaulting to Python 3.8 syntax or importing libraries you do not have installed.</Callout>

## Writing a Basic Script

```
> Create @scripts/process_csv.py
  
  What it does: reads a CSV of user emails and subscription dates,
  filters users whose subscription expired more than 30 days ago,
  and outputs a new CSV with just those users.
  
  Input: CSV with columns: email, subscription_end_date (ISO format)
  Output: CSV with the same columns, filtered
  
  Requirements:
  - Use the csv module (no pandas — keep dependencies minimal)
  - Accept input and output file paths as command-line arguments
  - Print a summary: "Processed N rows. Found M expired users."
  - Handle file not found gracefully
```

## Making Scripts Production-Ready

```
> Improve @scripts/process_csv.py to be production-ready:
  
  1. Add argparse for command-line arguments with --help documentation
  2. Add Python logging (not print) — INFO for progress, ERROR for failures
  3. Add a __main__ guard
  4. Add comprehensive docstrings
  5. Handle malformed CSV rows gracefully (skip and log)
  6. Add a --dry-run flag that shows what would be processed without writing output
```

## API Integration Scripts

```
> Create @scripts/sync_users.py
  
  This script syncs users from our Supabase database to a Mailchimp 
  email list. It should:
  
  1. Read users from Supabase using the supabase-py client
     (environment variables: SUPABASE_URL, SUPABASE_SERVICE_KEY)
  2. For each user, check if they exist in Mailchimp via API
     (MAILCHIMP_API_KEY, MAILCHIMP_LIST_ID env vars)
  3. Add new users, update changed email addresses
  4. Log every action to sync.log
  5. Print a summary at the end
  
  Handle Mailchimp API rate limiting with exponential backoff.
```

## Data Processing

```
> Create @scripts/analyze_quiz_results.py
  
  Reads quiz results JSON (array of { userId, moduleSlug, lessonSlug, score, passed, attemptedAt })
  
  Outputs:
  - Average score per lesson
  - Pass rate per lesson (% who passed on first try)
  - Lessons with highest failure rate (top 5)
  - Users who gave up (took quiz 3+ times and never passed)
  
  Output as a formatted report to stdout and to report.txt
```

## Debugging Python with Claude

```
> I am getting this error running @scripts/sync_users.py:
  
  Traceback (most recent call last):
    File "scripts/sync_users.py", line 47, in sync_user
      response = requests.post(url, json=payload, headers=headers)
  requests.exceptions.ConnectionError: HTTPSConnectionPool(host='us20.api.mailchimp.com')
  
  The script runs fine locally but fails in our CI environment.
  What could cause this in CI but not locally?
```

<Callout type="warning">Before running any AI-generated Python script that touches files, sends emails, or calls external APIs, create a virtualenv and install the dependencies in isolation — never run it directly in your system Python. Claude may specify libraries you do not have, and installing them globally can create version conflicts.</Callout>

```
  - Empty CSV
  - CSV with malformed dates (should skip and log)

  Use tmp_path fixture for test CSV files
  Put tests in @tests/test_process_csv.py
```

## Summary

Python scripts with Claude Code: specify the input/output contract, the libraries to use, and any error handling requirements. Claude writes clean, well-documented Python that follows the production patterns you need.

<KeyPoint>The key to great Python scripts from Claude is specifying the full contract upfront: Python version, allowed libraries, input format, output format, and error handling behavior — this produces scripts that are production-ready from the first iteration rather than requiring three rounds of fixes.</KeyPoint>
